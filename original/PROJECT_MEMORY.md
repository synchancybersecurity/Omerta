## 1. PROJECT OVERVIEW

Omertà is a dark noir-themed secure messaging webapp with mafia/underworld aesthetic.
- React 19 + TypeScript + Vite + Tailwind CSS v4 (shadcn/ui base)
- Express backend with SQLite (db.js), WebSocket for real-time
- tRPC 11.x with Hono for type-safe API (schema in place but API layer partially used)
- Drizzle ORM with MySQL schema defined but SQLite is actual DB
- File upload via multer
- Emoji cipher for "encrypted" messages
- CSS custom properties for full dynamic theming (dark/light + accent hue)

```bash
sleep 3 && zrok share public http://localhost:7777
```

## 7. BACKEND ENDPOINTS (server.js)

### Auth:
- `POST /api/auth/register` - `{ handle, passphrase }`
- `POST /api/auth/login` - `{ handle, passphrase }`

### Conversations:
- `POST /api/conversations` - create/get conversation
- `GET /api/conversations/:handle` - list conversations

### Messages:
- `POST /api/messages` - send message
- `GET /api/messages/:conversationId` - get messages
- `POST /api/messages/:id/burn` - burn message
- `PUT /api/messages/:id/edit` - edit message
- `DELETE /api/messages/:id/delete` - delete message

### Open Chat:
- `POST /api/open-chat` - send open chat message
- `GET /api/open-chat` - get open chat messages
- `PUT /api/open-chat/:id/edit` - edit
- `POST /api/open-chat/:id/delete` - delete

### Posts:
- `POST /api/posts` - create post
- `GET /api/posts` - get posts
- `POST /api/posts/:id/like` / `/dislike`
- `POST /api/posts/:id/share`
- `POST /api/posts/:id/burn`
- `PUT /api/posts/:id/edit`
- `DELETE /api/posts/:id/delete`

### Replies:
- `POST /api/posts/:id/reply` - create reply
- `GET /api/posts/:id/replies` - get replies

### User Settings:
- `GET /api/settings/:handle` - get settings
- `POST /api/settings/:handle` - save settings `{ theme, avatar }`

### Search:
- `GET /api/search/messages?q=query&handle=user`

### Escrow:
- `POST /api/escrow` - create
- `GET /api/escrow/:handle` - list
- `POST /api/escrow/:id/release|dispute|cancel`

### SMS:
- `POST /api/sms` - send
- `GET /api/sms/:handle` - get
- `POST /api/sms/:id/burn` - burn

### Upload:
- `POST /api/upload` - multer file upload

### WebSocket: `wss?://host/ws` - real-time notifications
